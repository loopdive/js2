# #7354 411-row ES5 sample (strict Prepared path)

`7354-o411.txt` lists 411 test262 files, with the `test/` prefix. The pass counts quoted in #7354 PRs come from the real
test262 runner, negatives included. Base: main bb9123f6a3 has 83 passes.

`prepared-census.mts` skips negative tests, so its numbers (e.g. 63) are not comparable. Every PR quotes this runner.

## Command

From a worktree of the commit you measure, with the test262 submodule present:

```bash
TEST262_PATH_FILTER_FILE="$PWD/plan/samples/7354-o411.txt" \
TEST262_COMPILER_PATH=ir \
TEST262_TARGET=standalone \
COMPILER_POOL_SIZE=3 TEST262_WORKERS=3 \
bash scripts/run-test262-vitest.sh > o411-run.log 2>&1
```

- `TEST262_COMPILER_PATH=ir` selects the strict Prepared front door, `wholeProgram: { kind: "prepared-program-required" }`.
- Do not pass `--target`; the runner rejects it.
- The runner writes one `.jsonl` per run under `benchmarks/results/`, plus logs. Untracked; delete them afterwards and
  never commit them.

## Tally

```bash
node plan/samples/7354-tally411.mjs benchmarks/results/<the run's>.jsonl
```

It prints one line per first-gap label, with a count. `pass` is the pass count. A label is the row's `status`, then its
`error` with the location prefix and unit ids stripped, cut to 120 characters.
