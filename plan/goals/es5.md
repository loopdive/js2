# Goal: es5

**Every ES5 (and ≤ES3) test262 test that does not require `eval` or `with` passes, in both the JS-host and standalone lanes.**

- **Status**: Active
- **Phase**: 2 (parallel with `core-semantics`; below the ES2015+ substrate work)
- **Target**: Host lane — close 1,772 reachable ES5 failures + 43 ≤ES3 failures.
  ES5 host is **6,499 / 8,931 = 73 %** today; the reachable sub-target
  (excluding `eval`/`with`) is **6,162 / 7,934 = 78 % → 100 %**.
  Standalone lane — ES5 is **5,273 / 8,931 = 59 %** (host-free pass definition);
  it trails host by 1,226 tests and is tracked by the `standalone` goals.
  Measured 2026-07-25 against the CI baselines in `loopdive/js2wasm-baselines`
  (see #3626 for the full census and method).
- **Dependencies**: `compilable` — a test must compile before it can pass, and
  44 of the ES5 failures are still compile errors/timeouts. `compilable` is met
  for this bucket (99.5 % of ES5 tests compile), so this goal is activatable now.
  It deliberately does **not** depend on `class-system`, `iterator-protocol` or
  `generator-model`: ES5 sits below all three.

## Why

ES5 is the floor everything else stands on. The current queue is dominated by
ES2015+ substrate work — class elements, private fields, iterators, generators,
TypedArray — and **none of it advances this target**: those tests live in the
ES2015/ES2020/ES2022 buckets. Finishing ES5 first means the semantics that every
later edition inherits (property descriptors, `[[Set]]`/`[[Delete]]` internal
methods, strict-mode error behaviour, `Function.prototype` plumbing) are correct
before more layers are built on them.

The scope is bounded and knowable: **8,931 tests**, not the 43k corpus. That
makes "100 %" a real, checkable target rather than a slogan.

## What makes 100 % unreachable today — the honest asterisk

**660 of the 2,432 ES5 failures (27 %) require `eval` or `with`.**

- **`eval`-dependent: 826 tests, 512 failing** (314 already pass). These are not
  skipped — they run and fail. Real `eval` support is a multi-issue programme of
  its own (`runtime-eval` goal: #1584, #2925, #2928, #2929, and the tiering
  issues #1263–#1266). Until one of those lands, ES5 cannot exceed
  **8,419 / 8,931 = 94 %**.
- **`with`-dependent: 171 tests, 148 failing** (23 pass). `with` is _partially_
  implemented — the compiler emits "with statement requires a proven closed
  object-literal shape before codegen", i.e. the static Tier-1 route of #1387
  shipped and the dynamic route did not. Completing it is a scoping decision
  (#671), not a documented wont-fix.

So the honest goal is: **reach 7,934 / 7,934 on the reachable set (currently
6,162), and treat the remaining 660 as gated on `runtime-eval` + #671.** ES5
100 % _is_ attainable, but only after `eval` lands; nobody should chase it before
then.

Note: `CLAUDE.md` still lists "Skip filters: eval, with, …". That line is stale —
these tests are executed and counted. Corrected in #3626.
