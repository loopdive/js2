# Goal: es5

**Every ES5 (and ≤ES3) test262 test passes in both the JS-host and standalone lanes, including tests that require `eval`, the `Function` constructor, or `with`.**

- **Status**: Active
- **Phase**: 2 (parallel with `core-semantics`; below the ES2015+ substrate work)
- **Target**: **9,029 / 9,029 ES5 tests pass in each lane.** On exact source
  `81125e5e248847a5df94c3e2a3a20016782e1df4` and corpus
  `b363f29d3c43c626dc852744ad64a0b48a003693` (2026-08-13), host is
  **7,408 / 9,029 = 82.05 %** with 1,621 nonpasses; standalone is
  **8,260 / 9,029 = 91.48 %** with 769 nonpasses. The same edition classifier
  and exact source/corpus pair must be used for every progress comparison.
- **Dependencies**: `compilable` — a test must compile before it can pass.
  Runtime `eval`/`Function` work and dynamic `with` scope work are required
  parts of this goal, not exclusions or follow-up ceilings. ES5 deliberately
  does **not** depend on `class-system`, `iterator-protocol`, or
  `generator-model`: ES5 sits below all three.

## Why

ES5 is the floor everything else stands on. The current queue is dominated by
ES2015+ substrate work — class elements, private fields, iterators, generators,
TypedArray — and **none of it advances this target**: those tests live in the
ES2015/ES2020/ES2022 buckets. Finishing ES5 first means the semantics that every
later edition inherits (property descriptors, `[[Set]]`/`[[Delete]]` internal
methods, strict-mode error behaviour, `Function.prototype` plumbing) are correct
before more layers are built on them.

The scope is bounded and knowable: **9,029 tests**, not the 43k corpus. That
makes "100 %" a real, checkable target rather than a slogan.

## Dynamic semantics are in the denominator

`eval`, the `Function` constructor, and `with` are no longer a boundary around
this goal. Source-shape partitions that identify them remain useful for routing
failures to the right implementation owners, but they must never be presented
as the completion denominator or as a reason to defer a failing ES5 test.

- **`eval` / `Function`**: complete the tiered runtime-eval programme tracked by
  the `runtime-eval` goal and issues #1263–#1266, #2925, #2928, and #2929.
- **`with`**: complete dynamic environment lookup and mutation through the IR
  and runtime scope model tracked by #671, #2663, #4179, and #4206.

The acceptance check is the unpartitioned edition total: host and standalone
must each report **9,029 passes, zero failures, zero compile errors/timeouts,
and zero skips**.

Note: `CLAUDE.md` still lists "Skip filters: eval, with, …". That line is stale —
these tests are executed and counted. Corrected in #3626.
