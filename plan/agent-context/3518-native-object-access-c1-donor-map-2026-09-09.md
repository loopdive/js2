## Principal finding and extraction boundary

`__extern_get` is not a self-contained map lookup. Its current implementation consists of an eager core plus ordered, mutating finalizer arms. It reaches accessor/method dispatch, carrier bags, prototype companions, native string flatten/equality, canonical undefined, and general ToPropertyKey conversion. ToPropertyKey itself reaches ToPrimitive/invocation and full number formatting. A literal `"then"` at one caller does not authorize narrowing the exported general getter or claiming these dependencies absent.

The coherent C1 boundary is **complete object-read recipes with explicit typed dependencies and explicit carrier/currentness facts**, not `ensureObjectRuntime`, a renamed `CodegenContext`, or arbitrary callbacks returning instruction arrays. C1 can freeze/reserve the getter/accessor interface before C2 fills invocation, but it cannot claim completed executable C1/Promise resources until the required invocation bindings are actually filled and authenticated. Reserve the strongly connected dependency group before fill; do not break the cycle with null-returning placeholders accepted as implementations.

The spec's five production paths can own the core layouts/read/accessor recipes and legacy adapters. Several real conditional read arms remain in other mixed modules. For every demanded arm, High must either assign its narrow donor extraction or supply an already-canonical owned pack. Their absence from the five-path write map is a **scope dependency**, never permission to omit them or import their mixed codegen owners into the backend.
