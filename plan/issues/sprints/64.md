### Retrospective — lessons → s65 process
1. **Full-gate for value-rep changes; ejects are signal, not churn.** The
   merge_group ejects this session were each correctly diagnosed (real+fixed /
   drift-recovered / conformance-negative-reverted / already-realized-shelved).
   Scoped sweeps repeatedly hid regressions the merge_group caught — value-rep /
   dispatch / shared-helper changes MUST go through the full gate (local-ci or
   merge_group), never a scoped sweep. (Memory: `project_broad_impact_validate_full_ci`.)
2. **The next big lever is the value-rep substrate, not point-fixes.** The
   sparse-array tail, open-object (#2580/#2573), and host-method dispatch (#983d)
   all converge on one dynamic-read representation gap (~390–1030 rows). Scoped to
   #2580, staged M0–M4: M0 landed (0-risk scaffold), M1 `.length` canary in flight.
   This is **s65's spine**.
3. **Re-validate against CURRENT main.** A fix's measured +N can be relative to a
   stale baseline already closed by intervening merges (#2040's phantom +311) —
   re-measure before concluding a fix is still needed.
4. **High message-velocity → crossed-message churn.** Verify live state before
   irreversible actions (agent shutdown especially); a held PR + silence ≠ stalled
   (devs doing deep verification don't touch the PR).
