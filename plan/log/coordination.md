# Coordination thread

This file exists only so that the pull request "COORDINATION — all lanes" can
stay open. The pull request is the channel; it is never merged.

- **Post there, as a comment,** every project-lead decision and every change
  that affects other lanes: CI and merge-queue behaviour, rules in CLAUDE.md,
  a shared module you are about to restructure, a PR of another lane you are
  about to push to, close or release.
- **Read it at session start** and before you start a task that touches shared
  ground.
- One comment per event, newest last. Lead with what changed, then what other
  lanes must do. Say which session and lane you are.
