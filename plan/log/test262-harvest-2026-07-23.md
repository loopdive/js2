## NEW patterns needing issues (>50, no existing owner)

Issue IDs were **not** allocated in this pass — `scripts/claim-issue.mjs --allocate`
hangs under concurrent agent load (>2 min even with `--no-pr-scan`), and hand-picking an
id is forbidden (a duplicate id passes PR CI and only fails in the `merge_group`,
wedging the queue). File these with a working allocator; ids 3536–3539 were already
reserved by in-flight agents at harvest time.

1. **Standalone dynamic import unsupported — 401 records.** Blocked on `compileMulti`
   providing internal module records + namespace objects. `goal: standalone-mode`,
   umbrella #1781. Sample: `test/language/expressions/dynamic-import/catch/nested-async-arrow-function-await-file-does-not-exist.js`.
2. **`Expected a SyntaxError to be thrown but no exception` — 207 (host).** Distinct from
   `negative_test_fail`; these reach the test body and fail an explicit assertion.
   Largely eval/indirect-eval shaped. Sample:
   `test/language/statements/class/elements/nested-private-derived-cls-indirect-eval-contains-superproperty-2.js`.
3. **TS `Signature declarations` / `Type annotations` parse errors — 112 in BOTH lanes.**
   Atomics/SharedArrayBuffer tests parsed as TypeScript. **%-neutral** (these should be
   *skipped* as SAB-dependent, not scored as failures) — file as scoring-accuracy, not a
   conformance win. Samples: `test/built-ins/Atomics/wait/good-views.js`,
   `test/built-ins/Atomics/waitAsync/bigint/no-spurious-wakeup-on-store.js`.
4. **`it should not get Symbol.iterator` — 84 (host).** Iterator-protocol conformance:
   `Symbol.iterator` is being read on a path where the spec forbids it. Concentrated in
   async-generator `yield*` tests.

## Non-regressions — explicitly checked, do NOT re-flag

- **Async `[object WebAssembly.Exception]` 1,272 → 1,360 is NOT a regression.** F2
  (#3469, merged 2026-07-19) gave the standalone/host-free lane an async completion
  channel, making ~3,258 previously-**unscored** async tests scoreable. More async tests
  reporting ⇒ more async failures visible. This is the observability fix working.
  The four historical WasmException issues (#1294, #1295, #1155, #1221) are all `done`
  and none covers the async path; #3417's umbrella is the current owner.
- **#2961 at 3,115 records is NOT a regression.** It is `status: done` — the citation is
  the leak *guard* naming itself while refusing a host import. The gap is the underlying
  unimplemented features, tracked under #1781 / #2860.
- **`async completion marker not observed` 4,617 → 51** is a large win (#3428 done), not
  a residual problem; #3421 tracks the tail.

## Corroboration of in-flight work

`TypeError: Cannot access property on null or undefined` is exactly the silent-null
declared-function-parameter defect currently being fixed (#3536) — independent
