When reporting sprint progress, use the format: `s{N}: {done}/{total} done`

Example: `s52: 17/82 done`

**Why:** User prefers this compact format over prose explanations or listing individual issues.

**How to apply:** Whenever asked "how many tasks are done" or giving a sprint status summary, lead with this format. Don't list done issues unless explicitly asked.
