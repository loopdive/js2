Compiled from pinned, published npm tarballs · tests/dogfood

What is measured

Each package is compiled from the exact, pinned, published npm tarball — not a reimplementation or a hand-picked snippet. The same tarball is also the native oracle, so any divergence is a compiler bug, never version skew.

Tests

Own test suite means the package's real tests run against the compiled output. Differential ops means a smaller, harness-authored set of representative calls is compared against native instead — a real signal, but not the same thing. The two are never conflated.

Performance

Compiled Wasm ( -O4 ) reports input knowledge and harness placement separately. In JS host , inputs are runtime dynamic from the compiler's perspective: Node owns them, the repeated-call loop, result observation, and assertion. In standalone , fixed inputs are static at compile time because the same package operation and test driver are compiled together with target: "standalone" . A generic optimizer may therefore prove and erase closed work; the row still records and verifies the result. The outer timing call is divided by the number of package operations. Both are calibrated medians of 9 rounds after warmup against the same native package, and the two input modes are never combined.

Divergences

Every divergence is a compiler bug, filed as its own issue and linked on the card — never worked around or hidden to make the numbers look better. Packages without a committed, reproducible harness are deliberately not listed.
